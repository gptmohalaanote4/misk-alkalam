# مسك الكلام

تطبيق جوال عربي يرسل لك يومياً — في موعدٍ تختاره — **حديثاً في فضائل الأعمال** من صحيحَي
البخاري ومسلم، و**مقولةً لأحد العلماء** بالتناوب، مع ذكر المرجع كاملاً تحت كل نص.

## لماذا تكلفة التشغيل صفر

الإشعارات **مجدولة محلياً على الجهاز** عبر `expo-notifications`، وكل إشعار يحمل نصّه معه.
لا يوجد خادم إرسال ولا رسائل Push، فلا فاتورة شهرية. التطبيق يعمل كاملاً بلا إنترنت
اعتماداً على محتوى مدمج، و Supabase (الخطة المجانية) اختياري للمزامنة ولوحة الأدمن فقط.

| البند | التكلفة |
|---|---|
| إرسال الإشعارات | ٠ — محلية على الجهاز |
| تجديد المحتوى آلياً | ٠ — GitHub Actions و GitHub Pages |
| قاعدة البيانات والمزامنة | ٠ — الخطة المجانية في Supabase |
| نشر أندرويد | ٢٥ دولاراً مرة واحدة |
| نشر iOS | ٩٩ دولاراً سنوياً — **مؤجَّل** (انظر أدناه) |

## خطة النشر المعتمدة

| الهدف | الطريق | التكلفة |
|---|---|---|
| **النشر العام** | **Google Play** — بناء عبر EAS | ٢٥ دولاراً مرة واحدة |
| الاستعمال على آيفون | **Expo Go** — بلا بناء ولا حساب مطوّر | صفر |
| App Store | Apple Developer Program | **مؤجَّل** |

الإشعارات المحلية تعمل في Expo Go، والتطبيق لا يستعمل Push أصلاً (كل إشعار مجدول
محلياً ويحمل نصّه)، فالتجربة على الآيفون كاملةُ الوظيفة:

```bash
cd app && npx expo start      # ثم امسح الرمز بتطبيق Expo Go على الآيفون
```

> لو أُدرج التطبيق لاحقاً تحت جمعية غير ربحية مسجّلة، فـApple تُعفي من رسوم البرنامج —
> وهو الباب الوحيد لنشرٍ مجاني على App Store.

## المحتوى يتجدّد من نفسه

لا يحتاج التطبيق من يُغذّيه بالنصوص: عملٌ مجدول أسبوعياً يحصد من «تراث» نصوصاً جديدة
بمراجعها، ويعتمدها في المستودع، وينشرها ملفاً ثابتاً يسحبه التطبيق.

```
tools/turath-harvest.mjs   →  يحصد من «تراث» بمرجع كامل، ببوّابات ترفض كل ما دون اليقين
tools/gen-content-json.mjs →  يبني public/content.json من البذرة
.github/workflows/content.yml →  أسبوعياً: يحصد، يتحقّق، يَعتمِد، وينشر على GitHub Pages
app/src/lib/feed.ts        →  التطبيق يسحب الملف ويتحقّق منه ثم يجدول محلياً
```

فإن تعذّر الوصول عمل التطبيق على ما لديه، وإن لم يُضبط شيء عمل على المحتوى المدمج.
التفاصيل والبوّابات في رأس `tools/turath-harvest.mjs`.

## البنية

```
app/                 تطبيق Expo / React Native (أندرويد + iOS)
  app/               المسارات (expo-router)
  src/components/    مكوّنات الواجهة ونظام التصميم
  src/lib/           محركات الجدولة والتسليم والإشعارات والمحتوى
  src/data/seed/     المحتوى المدمج (JSON)
  test/              خطّاف يسمح لمُشغّل اختبارات node بقراءة مصادر التطبيق
supabase/
  schema.sql         الجداول وسياسات RLS
  seed.sql           مولّد آلياً من نفس ملفات البذرة
public/
  content.json       مولّد آلياً — ما يُنشر على GitHub Pages ويسحبه التطبيق
tools/
  lib/                  طبقة «تراث» ومعالجة النص العربي، وقراءة البذرة وكتابتها
  turath-harvest.mjs    الحصد الآلي: محتوى جديد بمرجعه
  turath-import.mjs     توثيق البذرة القائمة، واعتماد نصّ المطبوع حرفياً
  gen-seed-sql.mjs      توليد seed.sql من المحتوى المدمج
  gen-content-json.mjs  توليد public/content.json من المحتوى المدمج
  validate-content.mjs  التحقّق من سلامة البذرة وبوّابة النشر
  gen-icons.mjs         توليد الأيقونات وشاشة البداية
```

## التشغيل

```bash
cd app
npm install
npx expo start
```

الإشعارات المحلية لا تعمل في Expo Go على أندرويد؛ تحتاج نسخة تطوير:

```bash
npx expo run:android      # أو: npx expo run:ios
```

قبل كل commit:

```bash
npm run typecheck         # tsc --noEmit
npm test                  # اختبارات محرّك التسليم والجدولة والطابور
npm run seed:check        # سلامة المحتوى المدمج
```

وبعد أي تعديل على `app/src/data/seed/` يُعاد توليد ملف البذرة:

```bash
node tools/gen-seed-sql.mjs
```

## ربط Supabase (اختياري)

1. أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com).
2. نفّذ `supabase/schema.sql` ثم `supabase/seed.sql` في SQL Editor.
3. أنشئ حسابك من Authentication → Users، ثم رقّه إلى أدمن:
   ```sql
   update public.profiles set role = 'admin' where email = 'your@email.com';
   ```
4. انسخ `app/.env.example` إلى `app/.env` واملأ العنوان والمفتاح العام.

## الصلاحيات

إضافة **عالم جديد**، وإضافة **مصدر غير «موقع تراث»**، وإضافة أي محتوى — كلها مقصورة
على الأدمن. الفرض يقع على الخادم في `schema.sql` عبر سياسات RLS ودالة `is_admin()`،
لا في الواجهة؛ فإخفاء الأزرار ليس هو الحماية.

قيود إضافية في قاعدة البيانات:

- `hadiths.collection` يقبل `bukhari` أو `muslim` فقط.
- المصدر المدمج «تراث» لا يُحذف ولا تتغيّر هويته (مُفعَّل بـ trigger).
- مصدر افتراضي واحد فقط (فهرس فريد جزئي).

## منهج المحتوى

- **الأحاديث:** من الصحيحين حصراً، وفي فضائل الأعمال وحدها.
- **المقولات:** من كتب أهل العلم، ومصدرها المعتمد «موقع تراث». العالم الأول: ابن القيم.
- يظهر تحت كل نص: اسم الكتاب ورقم المجلد والصفحة كلما توفّرت، ويظهر الاسم في الأعلى.

- **لا يُرسَل نصٌّ بلا مرجع كامل.** البوّابة مفروضة في ثلاثة مواضع: `--strict` في أداة
  التحقّق، و`content.json` لا يحمل ناقص المرجع، و`availablePools` في التطبيق تُسقطه
  وقت الإرسال ولو كان مخزَّناً على الجهاز من إصدار سابق.

### الطبعات المعتمدة

المرجع يُنسب إلى طبعةٍ بعينها لا إلى الكتاب مطلقاً، لأن الصفحات وأرقام الأحاديث تختلف
بين الطبعات. القائمة في `BOOKS` في `tools/lib/turath.mjs`:

| الكتاب | الطبعة |
|---|---|
| صحيح البخاري | السلطانية، بترقيم محمد فؤاد عبد الباقي |
| صحيح مسلم | تحقيق محمد فؤاد عبد الباقي |
| كتب ابن القيم | عطاءات العلم (محقَّقة، وترقيمها موافق للمطبوع) |

لإضافة كتاب: `node tools/turath-import.mjs --probe "عبارة منه"` يطبع مُعرّفه في «تراث».

## تشغيل التجديد الآلي

في المستودع على GitHub، مرة واحدة:

1. **ادمج هذا العمل في الفرع الافتراضي** (`main`) — الأعمال المجدولة لا تعمل إلا منه.
2. **Settings → Pages → Source** = `GitHub Actions`
3. **Settings → Actions → General → Workflow permissions** = `Read and write`
4. من تبويب Actions شغّل «تجديد المحتوى» يدوياً للتأكّد، ثم يعمل أسبوعياً من نفسه.

ثم اضبط عنوان الملف المنشور في التطبيق إن اختلف عن الافتراضي:

```bash
EXPO_PUBLIC_CONTENT_URL=https://<المستخدم>.github.io/<المستودع>/content.json
```

للتشغيل محلياً:

```bash
node tools/turath-harvest.mjs --dry-run           # يعرض ما سيضيفه بلا كتابة
node tools/turath-harvest.mjs --pages=150          # جولة فعلية
node tools/turath-import.mjs                       # توثيق مراجع البذرة القائمة
node tools/turath-import.mjs --adopt --scan        # ومعه: يأخذ نصّ المطبوع حرفياً
```

`--adopt` يأخذ النصّ من الصفحة **حرفاً بحرف** بحدوده المطبوعة — لا كلمة تُزاد ولا
تُحذف — فلا يبقى نصٌّ مذيَّلٌ بمرجعٍ لا يوافقه. وما تعذّر أخذه بحدٍّ مطبوع يبقى بلا
مرجع ويُطبع ليُراجَع. و`--scan` يحدّد المواضع بصفحات الكتاب لا بمحرّك البحث: أبطأ،
لكنه قاطعٌ لا يتعلّق بحدّ الطلبات، و`--budget` يحدّ صفحاته (٥٠٠٠ افتراضاً) فيقف
وقفةً نظيفة يكتب فيها ما وجد ويطبع ما لم يصل إليه ليُستأنف.

> «تراث» يحدّ من الطلبات المتسارعة بإرجاع **نتائج فارغة بلا رسالة خطأ**. الأدوات تتمهّل
> وتعيد المحاولة، و`TURATH_GAP_MS` يُبطئها أكثر عند الحاجة. فإن ظهر أن نصّاً «غير موجود»
> فتأكّد من هذا أولاً.
